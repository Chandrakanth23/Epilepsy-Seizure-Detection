This project implements an epilepsy seizure detection system using Random Forest (RF), Decision Tree (DT), and Gradient Boosting (GB) classifiers in MATLAB. The goal is to analyze EEG signals and classify them as seizure or non-seizure events with high accuracy.

Features:
1.  EEG Signal Processing: Reads EEG data, preprocesses it, and extracts relevant features.
  
2.  Feature Extraction: Time-domain and frequency-domain features are computed.

3.  Machine Learning Models: Implements Decision Tree, Random Forest, and Gradient Boosting classifiers.

4.  Performance Evaluation: Evaluates the models using accuracy, precision, recall, and F1-score.

High Accuracy:
1.  Random Forest & Gradient Boosting: 99% Accuracy
2.  Decision Tree & Gradient Boosting: 97% Accuracy

Requirements
1.  MATLAB (R2020a or later recommended)
2.  Signal Processing Toolbox
3.  Statistics and Machine Learning Toolbox
